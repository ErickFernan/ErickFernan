## 📂 Projetos em Destaque

### 🛡️ [Arquitetura Desaclopada para Petshop (Modular)](https://github.com/ErickFernan/APIPetShop)
*Django REST Framework, Docker, Keycloak, MinIO*

Mais do que uma API de gestão, este projeto implementa uma **infraestrutura completa e desacoplada**, simulando um ambiente de produção real.
- **Segurança Avançada:** Integração com **Keycloak** para gestão de identidade e acesso (IAM).
- **Object Storage:** Implementação de armazenamento de mídia compatível com S3 usando **MinIO**, desacoplando arquivos do servidor de aplicação.
- **Robustez:** Uso de transações atômicas para garantir integridade de dados financeiros e operacionais.
- **DevOps:** Ambiente totalmente conteinerizado com **Docker Compose**.

### 🏭 [Simulação Industrial Real-Time (High Performance)](https://github.com/ErickFernan/TCC_AltoForno_Django)
*C#, TCP/IP, Controle de Concorrência*

Sistema de missão crítica desenvolvido para simular a automação de um Alto-Forno industrial.
- **Controle de Concorrência:** Implementação manual de **Mutex e Semáforos** para gerenciar recursos compartilhados sem "race conditions".
- **Comunicação em Rede:** Protocolo TCP customizado para transmissão de dados em tempo real.
- **Complexidade Algorítmica:** Lógica matemática pesada para cálculo de carga e vazão.

### 🤖 [Algoritmos de Navegação Robótica](https://github.com/ErickFernan/Robo-terrestre-Pioneer-3dx)
*Matlab, V-Rep, Lógica Matemática*

Implementação de algoritmos de **Campos Potenciais** para navegação autônoma e desvio de obstáculos. Demonstra capacidade de transformar equações matemáticas complexas em código funcional e eficiente.
